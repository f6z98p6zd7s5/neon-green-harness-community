# Contributing

1. Search existing Issues and Discussions before opening a new one.
2. Explain the user-visible problem before proposing a tool or implementation.
3. Include evidence, reproduction steps and tradeoffs when possible.
4. Never publish secrets, personal data or private repository content.
5. Suggestions may be challenged with pre-mortem, cost, security and simplicity
   questions. That is design review, not rejection of the contributor.
6. Product code contributions are not accepted here while the source remains
   private. This gateway currently accepts ideas, feedback and public-preview
   reports.
