# Security Policy

## Supported scope

The public community gateway contains forms and documentation only. The Neon
Green Harness product remains private during pre-production.

## Reporting

1. Do not open a public Issue for a vulnerability.
2. Use GitHub private vulnerability reporting when the Security tab offers
   `Report a vulnerability`.
3. If that channel is unavailable, do not publish technical exploit details;
   wait for the private reporting channel to be restored.
4. Never send credentials, tokens, private keys or customer data as evidence.

## Response

1. A report is acknowledged before remediation timing is promised.
2. Severity is based on demonstrated impact and reachable attack path.
3. Fix claims require revalidation of the original vulnerable path.
